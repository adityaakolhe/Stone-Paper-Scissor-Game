# Stone-Paper-Scissor-Game
A simple Rock Paper Scissors game built with Python where the player competes against the computer in a 3-round match. Features random computer moves, score tracking, and final winner announcement.


## ✨ Features

- 🎲 Play against the computer
- 🔀 Random computer moves
- 🏆 3-round game system
- 📊 Automatic score tracking
- 🎉 Final winner announcement
- 💻 Beginner-friendly Python project

---

## 🛠️ Technologies Used

- Python 3
- `random` module
